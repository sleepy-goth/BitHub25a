# Esercizi svolti — 1.A Notazione asintotica
Esercizi svolti per la casistica 1.A degli esami di ASD (prof. Gualà): verificare relazioni asintotiche tra funzioni tramite il calcolo del limite $\lim_{n\to\infty} f(n)/g(n)$ — se $\to 0$ allora $f = o(g)$; se $\to \infty$ allora $f = \omega(g)$; se $\to c \ne 0$ finito allora $f = \Theta(g)$. Vedi [[Casistiche d'Esame Modulo I]] per il catalogo delle casistiche, [[Piano Esame ASD - Modulo I]] per la checklist di preparazione e [[02 - Notazioni Asintotiche]] per la teoria.
## Confronto tra polinomi puri
> [!question] Traccia tipica
> Date due funzioni $n^a$ e $n^b$ con $a, b$ razionali (eventualmente frazionari), stabilire la relazione asintotica corretta.

**Svolgimento.** Il rapporto $n^a / n^b = n^{a-b}$: se $a > b$ il limite è $\infty$ (quindi $\omega$), se $a < b$ è $0$ (quindi $o$), se $a = b$ è $1$ (quindi $\Theta$). Le radici vanno riscritte come esponenti frazionari prima di procedere: $\sqrt{n} = n^{1/2}$, $\sqrt[3]{n} = n^{1/3}$.

**Esempio 1.** $\sqrt{n} = \Theta(n^{2.5})$?
$$\lim_{n\to\infty} \frac{n^{1/2}}{n^{2.5}} = \lim_{n\to\infty} n^{-2} = 0 \implies \sqrt{n} = o(n^{2.5})$$
**Risultato:** FALSO.

**Esempio 2.** $\sqrt{n} = \Theta(n^{1/3})$?
$$\lim_{n\to\infty} \frac{n^{1/2}}{n^{1/3}} = \lim_{n\to\infty} n^{1/6} = \infty \implies n^{1/2} = \omega(n^{1/3})$$
Il rapporto diverge, quindi non è $\Theta$.
**Risultato:** FALSO.

**Esempio 3.** $n^{1/2} = \omega(n^{1/3})$?
Come nell'esempio precedente, $\lim_{n\to\infty} n^{1/2-1/3} = \lim_{n\to\infty} n^{1/6} = \infty$.
**Risultato:** VERO.

**Trappola:** le radici sono esponenti frazionari ($\sqrt{n} = n^{1/2}$, $\sqrt[3]{n} = n^{1/3}$); convertire prima di confrontare gli esponenti.
## Polinomiale × log vs polinomiale puro
> [!question] Traccia tipica
> Stabilire la relazione asintotica tra $n^a \log^k n$ e $n^b$.

**Svolgimento.** Se $a \ne b$, l'esponente di $n$ domina e il fattore $\log^k n$ è irrilevante. Se $a = b$, rimane il confronto tra $\log^k n$ e la costante $1$, che dà $\omega$ per $k > 0$.

**Esempio 1.** $n\log^2 n = o(n^2)$?
$$\lim_{n\to\infty} \frac{n\log^2 n}{n^2} = \lim_{n\to\infty} \frac{\log^2 n}{n} = 0$$
**Risultato:** VERO.

**Esempio 2.** $n + n^2\log^2 n = o(n^2\log n)$?
Il termine dominante a numeratore è $n^2\log^2 n$.
$$\lim_{n\to\infty} \frac{n^2\log^2 n}{n^2\log n} = \lim_{n\to\infty} \log n = \infty$$
Il limite diverge, quindi la relazione $o$ è falsa.
**Risultato:** FALSO.

**Esempio 3.** $n\log^2 n = o((n+3)\log^4 n)$?
Poiché $n + 3 \sim n$, si ha $(n+3)\log^4 n \sim n\log^4 n$.
$$\lim_{n\to\infty} \frac{n\log^2 n}{n\log^4 n} = \lim_{n\to\infty} \frac{1}{\log^2 n} = 0$$
**Risultato:** VERO.

**Trappola:** $n^2\log^2 n \ne \Theta(n^2\log n)$: il fattore $\log$ extra non può essere assorbito nella notazione $\Theta$.
## Polilogaritmico vs polinomiale/radice
> [!question] Traccia tipica
> Stabilire la relazione asintotica tra $\log^k n$ e $n^\varepsilon$ per $k \ge 1$, $\varepsilon > 0$.

**Svolgimento.** Vale sempre $\log^k n = o(n^\varepsilon)$ per qualsiasi $k \ge 1$ e $\varepsilon > 0$ fissi. Ogni potenza di $n$, per piccola che sia, domina qualsiasi potenza del logaritmo. Il limite si valuta con la regola di de l'Hôpital iterata o con la sostituzione $n = e^t$.

**Esempio 1.** $\log^4 n = o(\sqrt[3]{n})$?
$$\lim_{n\to\infty} \frac{\log^4 n}{n^{1/3}} = 0 \qquad \text{(legge standard: poli-log } o \text{ di qualsiasi potenza positiva di } n\text{)}$$
**Risultato:** VERO.

**Esempio 2.** $\log^2 n = \Theta(\sqrt{n})$?
$$\lim_{n\to\infty} \frac{\log^2 n}{n^{1/2}} = 0 \implies \log^2 n = o(\sqrt{n})$$
Il limite è $0$, non una costante positiva.
**Risultato:** FALSO.

**Esempio 3.** $n^2 = \Omega(n^{2.001}/\log^{2001} n)$?
$$\lim_{n\to\infty} \frac{n^2}{n^{2.001}/\log^{2001} n} = \lim_{n\to\infty} \frac{n^2\log^{2001} n}{n^{2.001}} = \lim_{n\to\infty} \frac{\log^{2001} n}{n^{0.001}} = 0$$
Il limite è $0$, quindi $n^2 = o(n^{2.001}/\log^{2001} n)$, non $\Omega$.
**Risultato:** FALSO.

**Trappola:** la legge vale anche con $\varepsilon = 0.001$: $n^{0.001}$ domina qualsiasi $\log^j n$, per grande che sia $j$.
## Proprietà dei logaritmi
> [!question] Traccia tipica
> Semplificare espressioni con $\log_a n$, $\log n^k$, $\log\sqrt{n}$ o $\log_n n$ e stabilire la relazione asintotica.

**Svolgimento.** Regole chiave: cambio di base $\log_a n = (\ln n)/(\ln a) = \Theta(\log n)$ per $a > 1$ fissa; $\log n^k = k\log n$; $\log\sqrt{n} = \tfrac{1}{2}\log n$; $\log_n n = 1$.

**Esempio 1.** $\log_3 n = \Theta(\log n)$?
$$\log_3 n = \frac{\ln n}{\ln 3} = \frac{1}{\ln 3} \cdot \log_2 n$$
Il rapporto con $\log_2 n$ è la costante $1/\ln 3$.
**Risultato:** VERO.

**Esempio 2.** $\log_2 n = \Theta(\log n^2)$?
$$\log n^2 = 2\log n \implies \lim_{n\to\infty} \frac{\log_2 n}{2\log_2 n} = \frac{1}{2}$$
Rapporto costante positivo.
**Risultato:** VERO.

**Esempio 3.** $\log\sqrt{n} = \Theta(\log n)$?
$$\log\sqrt{n} = \frac{1}{2}\log n \implies \text{rapporto } \frac{1}{2} \text{ (costante)}$$
**Risultato:** VERO.

**Trappola:** basi variabili danno comportamenti non standard: $\log_{n+3} 3 = \ln 3 / \ln(n+3) \to 0$, quindi non è $\Theta(\log n)$ né $\Theta(1)$.
## Logaritmi iterati e log-radice
> [!question] Traccia tipica
> Stabilire la relazione asintotica tra $\log\log n$, $\sqrt{\log n}$ e $\log n$.

**Svolgimento.** La gerarchia è $\log\log n \ll \sqrt{\log n} \ll \log n$. Si risolve con la sostituzione $t = \log n \to \infty$ e si riconduce a limiti del tipo $\log t\,/\,t^\alpha \to 0$ per $\alpha > 0$.

**Esempio 1.** $\log\log n = o(\log n)$?
Poniamo $m = \log n \to \infty$; il rapporto diventa $(\log m) / m \to 0$.
**Risultato:** VERO.

**Esempio 2.** $\log\log n = o(\sqrt{\log n})$?
Poniamo $t = \log n$; il rapporto è $(\log t) / \sqrt{t} \to 0$ (log su radice tende a zero).
**Risultato:** VERO.

**Esempio 3.** $\sqrt{\log\log n} = o(\log\log n)$?
Poniamo $u = \log\log n \to \infty$; il rapporto è $\sqrt{u}/u = 1/\sqrt{u} \to 0$.
**Risultato:** VERO.

**Trappola:** $\sqrt{\log n} = \omega(\log\log n)$; non confondere $\sqrt{\log n}$ (radice del log) con $\log\log n$ (log iterato).
## Potenze del logaritmo
> [!question] Traccia tipica
> Confrontare $\log^a n$ e $\log^b n$ con $a \ne b$, oppure $\log^a n$ e $\sqrt{\log n} = \log^{1/2} n$.

**Svolgimento.** Sostituzione $u = \log n \to \infty$: si confrontano $u^a$ e $u^b$ come polinomi. Se $a > b$ domina il primo, se $a < b$ il secondo.

**Esempio 1.** $\log^2 n = o(\log^{30} n)$?
Con $u = \log n$: $u^2 / u^{30} = u^{-28} \to 0$.
**Risultato:** VERO.

**Esempio 2.** $\log^2 n = \omega(\sqrt{\log n})$?
$\sqrt{\log n} = \log^{1/2} n$; con $u = \log n$: $u^2 / u^{1/2} = u^{3/2} \to \infty$.
**Risultato:** VERO.

**Esempio 3.** $\sqrt{\log n} = o(\log^{3/2} n)$?
Con $u = \log n$: $u^{1/2} / u^{3/2} = u^{-1} \to 0$.
**Risultato:** VERO.

**Trappola:** $\log^2 n$ significa $(\log n)^2$, non $\log(\log n)$; la notazione esponenziale si applica alla funzione intera.
## Frazioni razionali con radici
> [!question] Traccia tipica
> Determinare l'ordine asintotico di una frazione del tipo $(n^a + \text{termini minori}) / (n^b + \text{termini minori})$.

**Svolgimento.** A numeratore e denominatore conta solo il termine dominante. Riscrivere le radici come esponenti frazionari, poi applicare il rapporto dei termini dominanti: l'ordine è $\Theta(n^{a-b})$.

**Esempio 1.** $(n^3 + \log n)/\sqrt{n} = \Theta(n^{5/2})$?
Termine dominante: $n^3 / n^{1/2} = n^{5/2}$.
**Risultato:** VERO. **Complessità:** $\Theta(n^{5/2})$.

**Esempio 2.** $(n\sqrt{n} + \log n)/(n^3 + 3) = \Theta(\log n)$?
$n\sqrt{n} = n^{3/2}$; termine dominante: $n^{3/2} / n^3 = n^{-3/2} \to 0$. L'ordine è $\Theta(n^{-3/2})$, non $\Theta(\log n)$.
**Risultato:** FALSO.

**Esempio 3.** $(n^2\sqrt{n} + n)/\sqrt{n} = \Theta(n^2)$?
$n^2\sqrt{n} = n^{5/2}$; termine dominante: $n^{5/2} / n^{1/2} = n^2$.
**Risultato:** VERO. **Complessità:** $\Theta(n^2)$.

**Trappola:** $n\sqrt{n} = n^{3/2}$, non $n^2$; raccogliere correttamente i fattori prima di confrontare.
## Identità a^(log n) = n^(log a)
> [!question] Traccia tipica
> Semplificare espressioni del tipo $a^{\log_b n}$ e confrontarle con altre funzioni.

**Svolgimento.** L'identità chiave è $a^{\log_b n} = n^{\log_b a}$. Una volta riscritta come potenza di $n$, si confronta normalmente. Attenzione: la base del logaritmo deve coincidere con la base dell'esponenziale.

**Esempio 1.** $4^{\log n} = O(\log\log n)$?
$4^{\log_2 n} = n^{\log_2 4} = n^2$. Allora $n^2 = O(\log\log n)$? No, poiché $n^2 \gg \log\log n$.
**Risultato:** FALSO.

**Esempio 2.** $2^{\log n} = \omega(\sqrt[3]{n})$?
$2^{\log_2 n} = n^{\log_2 2} = n$. Allora $n = \omega(n^{1/3})$? Sì: $n / n^{1/3} = n^{2/3} \to \infty$.
**Risultato:** VERO.

**Esempio 3.** $\sqrt{2^{\log n}} = o(n^3)$?
$\sqrt{2^{\log_2 n}} = \sqrt{n} = n^{1/2}$. Allora $n^{1/2} = o(n^3)$? Sì.
**Risultato:** VERO.

**Trappola:** la base del logaritmo deve coincidere con la base dell'esponenziale: $4^{\log_2 n} = n^{\log_2 4} = n^2$, non $n^4$.
## Funzioni sub-polinomiali
> [!question] Traccia tipica
> Confrontare $2^{\sqrt{\log n}}$ o $2^{\log^2 n}$ con funzioni polinomiali o esponenziali.

**Svolgimento.** Si confrontano i logaritmi: $\log(2^{f(n)}) = f(n)\cdot\log 2 = f(n)$ (in base $2$), contro $\log(n^k) = k\log n$. Se $f(n) \ll k\log n$ allora $2^{f(n)} = o(n^k)$; se $f(n) \gg k\log n$ allora $2^{f(n)} = \omega(n^k)$.

**Esempio 1.** $2^{\sqrt{\log n}} = o(n^3)$?
$\log(2^{\sqrt{\log n}}) = \sqrt{\log n}$ contro $\log(n^3) = 3\log n$. Poiché $\sqrt{\log n} = o(\log n)$, la tesi vale.
**Risultato:** VERO.

**Esempio 2.** $2^{\sqrt{\log n}} = o(\sqrt{n})$?
$\log(2^{\sqrt{\log n}}) = \sqrt{\log n}$ contro $\log(\sqrt{n}) = \tfrac{1}{2}\log n$. Poiché $\sqrt{\log n} = o(\log n)$, la tesi vale.
**Risultato:** VERO.

**Esempio 3.** $2^{\log^2 n} = \Omega(n^{10})$?
$\log(2^{\log^2 n}) = \log^2 n$ contro $\log(n^{10}) = 10\log n$. Per $n$ grande $\log^2 n > 10\log n$, quindi $2^{\log^2 n} = \omega(n^{10})$.
**Risultato:** VERO.

**Trappola:** $2^{\log^2 n} = n^{\log n}$, super-polinomiale ma sub-esponenziale; non va confuso con $2^n$.
## Esponenziali a basi diverse
> [!question] Traccia tipica
> Confrontare $a^n$ e $b^n$ con $a, b > 1$, $a \ne b$.

**Svolgimento.** Il rapporto è $(a/b)^n$: se $a > b$ tende a $\infty$ ($\omega$); se $a < b$ tende a $0$ ($o$). Non può mai essere $\Theta$ con basi distinte.

**Esempio 1.** $2^n = o(3^n)$?
$(2/3)^n \to 0$.
**Risultato:** VERO.

**Esempio 2.** $3^n = \Theta(2^n)$?
$(3/2)^n \to \infty$, quindi $3^n = \omega(2^n)$, non $\Theta$.
**Risultato:** FALSO.

**Esempio 3.** $4^n = \omega(3^n)$?
$(4/3)^n \to \infty$.
**Risultato:** VERO.

**Trappola:** una base $< 1$ produce una sequenza decrescente (es. $(3/7)^n \to 0$); verificare sempre che $a, b > 1$ prima di concludere.
## Esponenziale vs polinomiale
> [!question] Traccia tipica
> Confrontare $a^n$ (con $a > 1$ fissa) e $n^k$ per qualsiasi $k$ fissato.

**Svolgimento.** Per ogni $a > 1$ e $k$ fissati vale $n^k = o(a^n)$, cioè l'esponenziale domina qualsiasi polinomio. Quindi $a^n = \omega(n^k)$.

**Esempio 1.** $2^n = O(n^{100})$?
$2^n / n^{100} \to \infty$, quindi $2^n = \omega(n^{100})$, non $O$.
**Risultato:** FALSO.

**Esempio 2.** $n^2 = \omega(2^n)$?
È il contrario: $n^2 = o(2^n)$.
**Risultato:** FALSO.

**Esempio 3.** $2^{n/2} = \Omega(n^{200})$?
$2^{n/2} = (\sqrt{2})^n$ è un esponenziale con base $\sqrt{2} > 1$, quindi domina $n^{200}$.
**Risultato:** VERO.

**Trappola:** attenzione alla direzione: è $2^n = \omega(n^k)$, non $n^k = \omega(2^n)$; l'esponenziale domina il polinomio, non il contrario.
## Costante additiva all'esponente
> [!question] Traccia tipica
> Confrontare $2^{n+c}$ e $2^n$ per $c$ costante fissa.

**Svolgimento.** $2^{n+c} = 2^c \cdot 2^n$; il fattore $2^c$ è una costante moltiplicativa, quindi $2^{n+c} = \Theta(2^n)$ per ogni costante $c$.

**Esempio 1.** $2^{n+2} = \Theta(2^n)$?
$2^{n+2} = 4 \cdot 2^n$; rapporto $= 4$ (costante).
**Risultato:** VERO.

**Esempio 2.** $2^n = \Theta(2^{n-10})$?
$2^n / 2^{n-10} = 2^{10} = 1024$ (costante).
**Risultato:** VERO.

**Esempio 3.** $2^{n+8} = \Theta(2^{n-8})$?
$2^{n+8} / 2^{n-8} = 2^{16}$ (costante).
**Risultato:** VERO.

**Trappola:** non confondere costante additiva ($2^{n+c} \to \Theta(2^n)$) con coefficiente moltiplicativo nell'esponente ($2^{2n} = 4^n \ne \Theta(2^n)$).
## Esponente scalato
> [!question] Traccia tipica
> Confrontare $2^{cn}$ e $2^{dn}$ con $c \ne d$, oppure riconoscere l'identità $2^{2n} = 4^n$.

**Svolgimento.** Il rapporto $2^{cn}/2^{dn} = 2^{(c-d)n}$: se $c \ne d$ questo tende a $0$ o a $\infty$, mai a una costante, quindi non è mai $\Theta$ tra funzioni con esponente scalato diverso.

**Esempio 1.** $2^{2n} = \Theta(4^n)$?
$2^{2n} = (2^2)^n = 4^n$; sono la stessa funzione.
**Risultato:** VERO.

**Esempio 2.** $2^{2n} = \omega(2^{1.9n})$?
$2^{2n} / 2^{1.9n} = 2^{0.1n} \to \infty$.
**Risultato:** VERO.

**Esempio 3.** $2^{n+2} = \Theta(2^{n/2})$?
$2^{n+2} / 2^{n/2} = 4 \cdot 2^{n/2} \to \infty$; quindi $2^{n+2} = \omega(2^{n/2})$.
**Risultato:** FALSO.

**Trappola:** $2^{2n} = (2^n)^2 \ne 2 \cdot 2^n$; $2^{n/2} = (\sqrt{2})^n$.
## Somma di esponenziali
> [!question] Traccia tipica
> In una somma del tipo $a^n + b^n$ (con $a > b$) o $a^n + n^k$, determinare il termine dominante.

**Svolgimento.** In una somma domina asintoticamente il termine più grande; gli altri sono trascurabili. Se $a > b > 1$, allora $a^n + b^n = \Theta(a^n)$. Se uno dei termini è super-esponenziale, domina lui.

**Esempio 1.** $2^n = \Theta(2^n + 1.5^n)$?
$1.5^n = o(2^n)$, quindi $2^n + 1.5^n \sim 2^n$.
**Risultato:** VERO.

**Esempio 2.** $2^n = \Theta(2^n + n^3)$?
$n^3 = o(2^n)$, quindi $2^n + n^3 \sim 2^n$.
**Risultato:** VERO.

**Esempio 3.** $2^n = o(2^n + n^n)$?
$n^n = \omega(2^n)$, quindi $2^n + n^n \sim n^n \gg 2^n$.
**Risultato:** VERO.

**Trappola:** in $2^n + n^n$ domina $n^n$, non $2^n$; controllare sempre quale termine è il più grande.
## Esponente con addendo non costante
> [!question] Traccia tipica
> Confrontare $2^{n+f(n)}$ e $2^n$ quando $f(n)$ non è costante (es. $f(n) = \log n$).

**Svolgimento.** $2^{n+f(n)} = 2^n \cdot 2^{f(n)}$. Se $f(n) \to \infty$ anche $2^{f(n)} \to \infty$ e il rapporto non è costante: non si è nel caso $\Theta$. Con $f(n) = \log_2 n$: $2^{\log_2 n} = n$, quindi $2^{n+\log n} = n \cdot 2^n = \omega(2^n)$.

**Esempio 1.** $2^n = \Theta(2^{n+\log n})$?
$2^{n+\log_2 n} / 2^n = 2^{\log_2 n} = n \to \infty$; il rapporto diverge.
**Risultato:** FALSO.

**Esempio 2.** $2^n = \Theta(2^{n-\log n})$?
$2^{n-\log_2 n} = 2^n / n$; quindi $2^n / (2^n/n) = n \to \infty$; il rapporto diverge.
**Risultato:** FALSO.

**Esempio 3.** $2^{n+\log n} = \omega(2^n)$?
$2^{n+\log_2 n} / 2^n = n \to \infty$.
**Risultato:** VERO.

**Trappola:** costante additiva $\Rightarrow \Theta$; addendo $\log n$ nell'esponente $\Rightarrow$ il rapporto cresce come $n$, quindi $\omega$.
## o, omega vs Theta
> [!question] Traccia tipica
> Data una relazione $f = o(g)$ o $f = \omega(g)$, verificare se è corretta quando il limite del rapporto è una costante positiva.

**Svolgimento.** Se $\lim_{n\to\infty} f(n)/g(n) = c \in (0,\infty)$, allora $f = \Theta(g)$ e sono false sia $f = o(g)$ (che richiederebbe limite $0$) sia $f = \omega(g)$ (che richiederebbe limite $\infty$).

**Esempio 1.** $2^{n+2} = \omega(2^n)$?
$2^{n+2}/2^n = 4$; limite costante $\Rightarrow$ è $\Theta$, non $\omega$.
**Risultato:** FALSO.

**Esempio 2.** $2^n = o(2^n + 8)$?
$(2^n+8)/2^n = 1 + 8/2^n \to 1$; limite $1 \Rightarrow$ è $\Theta$, non $o$.
**Risultato:** FALSO.

**Esempio 3.** $2^n = \omega(2^n + n^2)$?
$(2^n+n^2)/2^n = 1 + n^2/2^n \to 1$; limite $1 \Rightarrow$ è $\Theta$, non $\omega$.
**Risultato:** FALSO.

**Trappola:** $\omega$ richiede limite $\infty$; $o$ richiede limite $0$; con limite $c \ne 0$ finito la relazione è solo $\Theta$.
## Fattoriale vs esponenziale
> [!question] Traccia tipica
> Confrontare $n!$ con $a^n$ per $a$ fissa.

**Svolgimento.** Per la formula di Stirling, $n! \approx \sqrt{2\pi n}\,(n/e)^n$; questo cresce molto più velocemente di qualsiasi $a^n$ con $a$ fissa. Quindi $n! = \omega(a^n)$ per ogni $a > 0$ costante.

**Esempio 1.** $n! = \Theta(2^n)$?
Stirling implica $n!/2^n \to \infty$, quindi $n! = \omega(2^n)$, non $\Theta$.
**Risultato:** FALSO.

**Esempio 2.** $n! = \omega(2^n)$?
**Risultato:** VERO.

**Trappola:** gerarchia completa: $n^n \gg n! \gg a^n \gg n^k \gg \log^j n$; non confondere $n!$ con $n^n$.
## Funzioni super-esponenziali
> [!question] Traccia tipica
> Confrontare $n^n$, $n^{\sqrt{n}}$, $(\sqrt{n+1})^n$ e funzioni simili.

**Svolgimento.** Per $n^{f(n)}$ si confrontano i logaritmi: $\log(n^{f(n)}) = f(n)\log n$. Il rapporto tra le due funzioni ha come logaritmo la differenza $f(n)\log n - g(n)\log n = (f(n)-g(n))\log n$; se questa diverge a $\infty$ la prima funzione domina, se va a $-\infty$ domina la seconda.

**Esempio 1.** $2^n = o(2^n + n^n)$?
$n^n = \omega(2^n)$, quindi $2^n + n^n \sim n^n \gg 2^n$.
**Risultato:** VERO.

**Esempio 2.** $n^n = \Theta((\sqrt{n+1})^n)$?
$(\sqrt{n+1})^n = (n+1)^{n/2}$. Confronto tramite logaritmi: $\log(n^n) = n\log n$ contro $\log((n+1)^{n/2}) = \tfrac{n}{2}\log(n+1) \sim \tfrac{n}{2}\log n$. Il logaritmo del rapporto è $n\log n - \tfrac{n}{2}\log n = \tfrac{n}{2}\log n \to \infty$, quindi $n^n = \omega((\sqrt{n+1})^n)$.
**Risultato:** FALSO.

**Esempio 3.** $n^{\sqrt{n}} = \Theta(n^{\sqrt{n^2+1}})$?
$\log(n^{\sqrt{n}}) = \sqrt{n}\log n$ contro $\log(n^{\sqrt{n^2+1}}) = \sqrt{n^2+1}\log n \approx n\log n$. Rapporto dei logaritmi: $\sqrt{n}\log n\,/\,(n\log n) = 1/\sqrt{n} \to 0$, quindi $n^{\sqrt{n}} = o(n^{\sqrt{n^2+1}})$.
**Risultato:** FALSO.

**Trappola:** confrontare $n^{f(n)}$ via $f(n)\log n$: la funzione con esponente asintoticamente più grande domina sempre.
