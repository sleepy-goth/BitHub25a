# Esercizi svolti — 1.A Notazione asintotica
Dato un elenco di relazioni asintotiche ($O,\Omega,\Theta,o,\omega$), dire per ognuna se è **vera** o **falsa**. Metodo unico: il rapporto $\lim_{n\to\infty} f(n)/g(n)$ — se $\to 0$ allora $f=o(g)$; se $\to\infty$ allora $f=\omega(g)$; se $\to c\ne 0$ finito allora $f=\Theta(g)$ (e quindi né $o$ né $\omega$). Teoria: [[02 - Notazioni Asintotiche#Metodo operativo: i limiti|metodo dei limiti]] e [[02 - Notazioni Asintotiche#Gerarchia degli ordini di infinito|gerarchia di crescita]].

> [!info] Come affrontarlo — è un esercizio mnemonico
> All'esame questo blocco vale 16 punti **ma va chiuso in pochi minuti**: non c'è tempo per calcolare ogni limite da zero. L'obiettivo è riconoscere la **casistica a colpo d'occhio** e rispondere quasi a memoria; il limite si scrive **solo** quando la risposta non è immediata. Studia queste schede finché ogni riga "📄 dagli esami" la risolvi in testa in pochi secondi.
## 1 · Polinomi e radici puri
*Regola:* riscrivi le radici come esponenti ($\sqrt n=n^{1/2}$, $\sqrt[3]n=n^{1/3}$); in una somma conta **solo il termine dominante**, poi $n^a$ vs $n^b \Rightarrow$ rapporto $n^{a-b}$. Ripasso: [[02 - Notazioni Asintotiche#Velocità delle funzioni composte: il termine dominante|termine dominante]].

**📄 Dagli esami**

- $n^{1/4}\log n + \sqrt n = \Omega(n^{1/3})$ — *28/09/22, 18/02/25*

  → **VERO**: domina $\sqrt n=n^{1/2}$, e $n^{1/2}=\omega(n^{1/3})$.

- $n^{1/4}\log n + \sqrt{\log n} = \Omega(n^{1/3})$ — *30/01/23*

  → **FALSO**: niente $\sqrt n$, domina $n^{1/4}\log n$; $\dfrac{n^{1/4}\log n}{n^{1/3}}=\dfrac{\log n}{n^{1/12}}\to 0$, quindi è $o(n^{1/3})$.

- $n^{1/5}\log n + \sqrt{\log n} = o(n^{1/4})$ — *04/07/23*

  → **VERO**: $\dfrac{n^{1/5}\log n}{n^{1/4}}=\dfrac{\log n}{n^{1/20}}\to 0$.

- $n^{1.5} = \Theta\!\big(n^{\sqrt2+1}/\sqrt n\big)$ — *16/02/26*

  → **FALSO**: a destra $n^{\sqrt2+1-1/2}=n^{\sqrt2+0.5}\approx n^{1.91}\ne n^{1.5}$.

> [!warning] Il trabocchetto $\sqrt n$ vs $\sqrt{\log n}$
> Aggiungere $\sqrt n$ (vero polinomio, $n^{1/2}$) **cambia** il termine dominante; aggiungere $\sqrt{\log n}$ (sub-polinomiale) è **trascurabile**. Le due tracce sembrano identiche ma la risposta si ribalta.

**Inventati plausibili**

- $\sqrt[3]{n^2}+n = \Theta(n)$ → **VERO** ($n^{2/3}=o(n)$, domina $n$).

- $n^{0.99} = \omega(n)$ → **FALSO** ($n^{0.99}=o(n)$).

**Raro** — $n+\sqrt n = \Theta(n-\sqrt n)$ (*27/09/23*) → **VERO**: entrambi $\sim n$.
## 2 · Polinomiale × log vs polinomiale puro
*Regola:* se gli esponenti di $n$ differiscono, **decide $n$** e il $\log$ è irrilevante; se sono uguali decide il fattore $\log^k$.

**📄 Dagli esami**

- $n^2 = o(n^2\log^{30} n)$ — *16/07/24*

  → **VERO**: rapporto $1/\log^{30}n\to 0$.

- $n\log^2 n = o((n+3)\log^4 n)$ — *28/09/22*

  → **VERO**: $(n+3)\sim n$, rapporto $1/\log^2 n\to 0$.

- $n + n^2\log^2 n = o(n^2\log n)$ — *14/09/22*

  → **FALSO**: domina $n^2\log^2 n$, rapporto $\log n\to\infty$.

- $n^3 + n^2\log^2 n = o(n^2\log^{30} n)$ — *18/07/22, 13/06/24*

  → **FALSO**: domina $n^3$, e $\dfrac{n^3}{n^2\log^{30}n}=\dfrac{n}{\log^{30}n}\to\infty$.

- $\sqrt n\,\log n + \sqrt{\log n} = O(n)$ — *30/06/26*

  → **VERO**: domina $\sqrt n\,\log n=n^{1/2}\log n$, e $\dfrac{n^{1/2}\log n}{n}=\dfrac{\log n}{n^{1/2}}\to 0$ (quindi $o(n)$); $\sqrt{\log n}$ è trascurabile.

> [!warning] Il gap polinomiale batte qualsiasi polilog
> $n^3$ vs $n^2\log^{30}n$: il fattore extra $n$ vince su $\log^{30}n$ (per quanto grande l'esponente del log). Un $\log^k$ **non** colma mai un divario di grado in $n$.

**Inventati plausibili**

- $n^2\log n = \Theta(n^2\log^2 n)$ → **FALSO** (rapporto $\log n\to\infty$).
## 3 · Polilogaritmico vs radice/polinomio
*Regola:* $\log^k n = o(n^\varepsilon)$ per **ogni** $k$ fisso e $\varepsilon>0$: una potenza di $n$, anche minuscola, batte ogni potenza del log. Ripasso: [[02 - Notazioni Asintotiche#Gerarchia degli ordini di infinito|gerarchia]].

**📄 Dagli esami** *(stessa legge, tutte VERO)*

- $\log^4 n = o(\sqrt[3]n)$ — *14/09/22*

- $\log^4 n = o(\sqrt[4]n)$ — *25/07/23*

- $\log^3 n = o(\sqrt[5]n)$ — *12/09/23*

- $\log^2 n = o(\sqrt n)$ — *23/09/25*

**Inventati plausibili**

- $\log^{100} n = \Omega(n^{0.001})$ → **FALSO** (è $o$: $n^{0.001}$ domina).
## 4 · Frazioni razionali con radici
*Regola:* solo i termini dominanti di numeratore e denominatore; l'ordine è $\Theta(n^{a-b})$.

**📄 Dagli esami**

- $(n^3+\log n)/\sqrt n = \Theta(n^{2.5})$ — *04/07/23, 30/01/24*

  → **VERO**: $n^3/n^{1/2}=n^{5/2}$.

- $(\log n + n^{5/2})/(\sqrt n+1) = \Theta(n^2)$ — *18/07/25*

  → **VERO**: $n^{5/2}/n^{1/2}=n^2$.

- $(n^{3/2}+n^2)/(\sqrt n+1) = \Theta(n)$ — *09/09/25*

  → **FALSO**: $n^2/n^{1/2}=n^{3/2}\ne n$.

- $n\sqrt n = \Theta\!\big((n^2+1)/\sqrt n\big)$ — *23/09/25, 02/02/26*

  → **VERO**: a destra $n^2/n^{1/2}=n^{3/2}=n\sqrt n$.

- $(n\sqrt n+\log n)/\sqrt{n^3+3} = \Theta(\log n)$ — *18/07/22, 13/06/24*

  → **FALSO**: $n^{3/2}/n^{3/2}=\Theta(1)$, non $\Theta(\log n)$.
## 5 · Proprietà dei logaritmi
*Regola:* $\log_a n=\Theta(\log n)$ (base costante); $\log n^k=k\log n$; $\log\sqrt n=\tfrac12\log n$; $\log^k n$ resta $\Theta(\log n)$ **solo** se $k=1$.

**📄 Dagli esami**

- $\sqrt{\log n} = \Theta(\log\sqrt n)$ — *20/02/23*

  → **FALSO**: $\log\sqrt n=\tfrac12\log n$, e $\sqrt{\log n}=o(\log n)$.

- $\log^2 n = \Theta(\log n^2)$ — *26/06/25*

  → **FALSO**: $\log n^2=2\log n$, e $\log^2 n=\omega(\log n)$.

- $\log^3 n = \Theta(\log n)$ — *27/09/23*

  → **FALSO**: rapporto $\log^2 n\to\infty$.

> [!warning] $\log^k n$ vs $\log n^k$
> $\log^2 n=(\log n)^2$ (cresce come il quadrato del log); $\log n^2=2\log n=\Theta(\log n)$. Si scrivono quasi uguali, ma il primo è $\omega$ del secondo.

**Inventati plausibili**

- $\log_3 n = \Theta(\log_2 n)$ → **VERO** (cambio base = costante $1/\ln 3$).
## 6 · Logaritmi iterati e log-radice
*Regola:* sostituisci $u=\log n\to\infty$ e confronta come potenze/log di $u$. Gerarchia: $\log\log n \ll \sqrt{\log n} \ll \log n$.

**📄 Dagli esami**

- $\log\log n = o(\sqrt{\log n})$ — *18/02/25*

  → **VERO**: con $u=\log n$, $\dfrac{\log u}{\sqrt u}\to 0$.

- $\sqrt{\log n} = \omega(\log\log n)$ — *02/02/26, 30/06/26*

  → **VERO** (stessa gerarchia).

- $\log n = o\!\big(\sqrt{\log^3 n}\big)$ — *24/09/24*

  → **VERO**: $\sqrt{\log^3 n}=\log^{3/2}n$, rapporto $1/\sqrt{\log n}\to 0$.

- $\sqrt{\log\log n} = o(\log\log n)$ — *16/02/26*

  → **VERO**: con $u=\log\log n$, $1/\sqrt u\to 0$.

> [!warning] $\sqrt[4]{\log n}$ non è $O(\log\log n)$
> Tracce con $\sqrt[4]{\log n} = O(\log\log n)$ (*22/06/22, 30/01/23, 30/01/24*) sono **FALSE**: con $u=\log n$, $u^{1/4}=\omega(\log u)$. Ogni radice del log batte il log-del-log.
## 7 · Potenze del logaritmo
*Regola:* con $u=\log n$, $\log^a n$ vs $\log^b n$ si confrontano come $u^a$ vs $u^b$.

**📄 Dagli esami**

- $\log^2 n = o(\log^{30} n)$ — *18/07/22, 13/06/24*

  → **VERO** ($u^2/u^{30}\to 0$).

- $\log^2 n = \omega(\sqrt{\log n})$ — *16/07/24*

  → **VERO** ($u^2/u^{1/2}=u^{3/2}\to\infty$).
## 8 · Identità $a^{\log n}=n^{\log a}$ e funzioni sub-polinomiali
*Regola:* riscrivi $a^{\log_b n}=n^{\log_b a}$ (basi coincidenti!); per $2^{f(n)}$ confronta i logaritmi: $\log\!\big(2^{f(n)}\big)=f(n)$ contro $\log(n^k)=k\log n$.

**📄 Dagli esami**

- $2^{\log^2 n} = \Omega(n^{10})$ — *19/02/24*

  → **VERO**: $2^{\log^2 n}=n^{\log n}$, e $\log^2 n=\omega(10\log n)$.

- $2^{\sqrt{\log n}} = o(n^3)$ — *30/01/23, 04/07/23*

  → **VERO**: $\sqrt{\log n}=o(3\log n)$.

- $2^{\sqrt{\log n}} = \omega(\sqrt[3]n)$ — *28/09/22*

  → **FALSO**: è $o(n^{1/3})$ (stesso confronto, $\sqrt{\log n}=o(\tfrac13\log n)$).

- $2^n = \Theta(n^{\log n})$ — *16/07/24*

  → **FALSO**: $n^{\log n}=2^{\log^2 n}$ e $n=\omega(\log^2 n)$, quindi $2^n=\omega(n^{\log n})$.

- $n^{2.5} = \Theta\!\big(n^{3+\log n}/\sqrt n\big)$ — *30/06/26*

  → **FALSO**: a destra l'esponente è $3+\log n-\tfrac12=2.5+\log n$, cioè $n^{2.5}\cdot n^{\log n}$; poiché $n^{\log n}=2^{\log^2 n}=\omega(n^k)$, la destra è $\omega(n^{2.5})$. Trappola: l'esponente è $3+\log n$, non la somma $n^3+\log n$.

> [!warning] $2^{\log^2 n}$ è super-polinomiale ma sub-esponenziale
> $2^{\log^2 n}=n^{\log n}$: più grande di **ogni** $n^k$, ma più piccolo di $2^n$. Non confonderlo con $2^n$.
## 9 · Esponenziali: basi diverse e vs polinomiale
*Regola:* $a^n$ vs $b^n\Rightarrow (a/b)^n$ (mai $\Theta$ se $a\ne b$); ogni $a^n$ ($a>1$) domina ogni $n^k$.

**📄 Dagli esami**

- $2^n = o(3^n)$ — *22/06/22* → **VERO**

- $3^n = \Theta(2^n)$ — *19/02/24* → **FALSO** ($(3/2)^n\to\infty$)

- $4^n = \omega(3^n)$ — *09/09/24, 21/01/25* → **VERO**

- $(7/3)^n = \omega(2^n)$ — *12/09/23* → **VERO** ($7/3>2$)

- $(5/4)^n = o(2^n)$ — *27/09/23* → **VERO**

- $3^n = o(2^{2n})$ — *20/02/23* → **VERO** ($2^{2n}=4^n$, $3<4$)

- $2^n = O(n^{100})$ — *22/06/22* → **FALSO** ($2^n=\omega(n^{100})$)

- $2^n = \Omega(n^{200})$ — *19/02/24* → **VERO**

- $n^2 = o(n\log n)$ — *18/07/25* → **FALSO** (rapporto $n/\log n\to\infty$)
## 10 · Esponente: costante additiva vs fattore scalato
*Regola:* $2^{n+c}=2^c\cdot 2^n=\Theta(2^n)$ (costante additiva innocua); ma $2^{cn}$ con $c\ne 1$ **cambia base** ($2^{2n}=4^n$, $2^{n/2}=\sqrt2^{\,n}$) → mai $\Theta(2^n)$.

**📄 Dagli esami**

- $2^{n+20} = \Theta(2^n)$ — *16/07/24, 02/02/26* → **VERO**

- $2^{n+2} = \Theta(2^n)$ — *27/09/23* → **VERO**

- $2^{n+2} = \omega(2^n)$ — *28/09/22, 18/02/25* → **FALSO** (rapporto $=4$ costante → è $\Theta$)

- $2^{2n} = \omega(2^{1.9n})$ — *18/07/22, 25/07/23, 13/06/24* → **VERO** ($2^{0.1n}\to\infty$)

- $2^{1.5n} = \omega(2^n)$ — *23/09/25* → **VERO**

- $2^{2n} = \Theta(2^n)$ — *16/07/24* → **FALSO**

- $2^{n/2} = \Theta(2^n)$ — *16/02/26* → **FALSO**

- $2^{n/2} = o(2^n)$ — *30/06/26* → **VERO** ($2^{n/2}/2^n=2^{-n/2}\to 0$)

- $2^{n+2} = \Theta(2^{n/2})$ — *30/01/23, 30/01/24* → **FALSO** ($4\cdot 2^{n/2}\to\infty$, è $\omega$)

> [!warning] Additivo $\ne$ moltiplicativo nell'esponente
> $2^{n+c}\to\Theta(2^n)$ (costante che esce come fattore); $2^{cn}=(2^c)^n$ è un'altra base. Confondere $2^{n+2}$ con $2^{2n}$ è l'errore numero uno.
## 11 · Esponente con addendo non costante
*Regola:* $2^{n+f(n)}=2^n\cdot 2^{f(n)}$: se $f(n)\to\infty$ il rapporto **non** è costante. Con $f=\log n$: $2^{\log n}=n$.

**📄 Dagli esami**

- $2^n = \Theta(2^{n+\log n})$ — *20/02/23, 04/07/23*

  → **FALSO**: rapporto $2^{\log n}=n\to\infty$.

- $2^{n+\log n} = \omega(2^n)$ — *09/09/25*

  → **VERO** (stesso conto, direzione opposta).

- $n\cdot 2^n = \omega(2^{2n})$ — *19/02/24*

  → **FALSO**: $\dfrac{n\,2^n}{2^{2n}}=\dfrac{n}{2^n}\to 0$.

- $2^n = o(2^n\sqrt{\log n})$ — *27/09/23*

  → **VERO** (rapporto $\sqrt{\log n}\to\infty$).

- $2^n = \Theta(2^n\log\log n)$ — *12/09/23*

  → **FALSO** (rapporto $\log\log n\to\infty$).
## 12 · Somma di esponenziali (termine dominante)
*Regola:* in $a^n+b^n$ domina la base maggiore; un addendo polinomiale o costante accanto a $2^n$ è trascurabile, ma allora la somma è $\Theta(2^n)$ — quindi $o$/$\omega$ rispetto a $2^n$ sono **false**.

**📄 Dagli esami**

- $2^n = \Theta(2^n + 1.5^n)$ — *18/07/22, 25/07/23, 13/06/24* → **VERO**

- $2^n = \Theta(2^n + n^3)$ — *09/09/24, 21/01/25* → **VERO**

- $2^{2n} = \Theta(4^n + 2^{n/2})$ — *30/01/23* → **VERO** ($4^n=2^{2n}$ domina)

- $2^{2n} = \Theta(4^n + n^2)$ — *04/07/23* → **VERO**

- $2^n = o(2^n + n^2)$ — *18/07/22* → **FALSO** (somma $\Theta(2^n)$, limite $=1$)

- $2^n = o(2^n + 8)$ — *22/06/22* → **FALSO**

- $2^n = \omega(2^n + n^2)$ — *12/09/23* → **FALSO**

- $2^n/n^2 = \omega(2^{n/2})$ — *20/02/23*

  → **VERO**: $\dfrac{2^n/n^2}{2^{n/2}}=\dfrac{2^{n/2}}{n^2}\to\infty$.

> [!warning] Limite $=1$ ⇒ solo $\Theta$
> Quando la somma collassa sul termine dominante, il rapporto tende a una **costante** ($1$): allora vale $\Theta$, e sono **false** sia $o$ (richiede $0$) sia $\omega$ (richiede $\infty$). Vedi [[02 - Notazioni Asintotiche#Le cinque notazioni asintotiche|le 5 notazioni]].
## 13 · Fattoriale e super-esponenziali *(rari)*
*Regola:* gerarchia $n^n \gg n! \gg a^n \gg n^k$; per $n^{f(n)}$ confronta $f(n)\log n$.

**📄 Dagli esami**

- $n! = \Theta(2^n)$ — *24/09/24*

  → **FALSO**: per Stirling $n!=\omega(a^n)$ per ogni $a$ costante.

**Inventati plausibili**

- $n^{\sqrt n} = o(n^n)$ → **VERO** ($\sqrt n\log n = o(n\log n)$).

- $n^n = \Theta\!\big((\sqrt n)^n\big)$ → **FALSO** ($(\sqrt n)^n=n^{n/2}$, esponente metà).
