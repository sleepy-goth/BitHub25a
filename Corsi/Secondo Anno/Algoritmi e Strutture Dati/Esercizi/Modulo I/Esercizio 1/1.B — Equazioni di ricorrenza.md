# Esercizi svolti — 1.B Equazioni di ricorrenza
Raccoglie esercizi svolti per la casistica 1.B del [[Casistiche d'Esame Modulo I]]; da usare insieme a [[Piano Esame ASD - Modulo I]] e con il ripasso su [[03 - Equazioni di Ricorrenza]] e [[01 - Il Problema di Fibonacci]].
## Master Theorem — caso 2
> [!question] Traccia tipica
> Data la ricorrenza $T(n) = aT(n/b) + f(n)$, determinare l'ordine asintotico quando $f(n) = \Theta(n^{\log_b a})$ (costo di ricombinazione bilanciato con il costo delle foglie).

**Svolgimento.** Si calcola il valore critico $n^{\log_b a}$ e si verifica che $f(n)$ stia nello stesso $\Theta$. Quando ciò accade (caso 2), il costo è distribuito uniformemente su tutti i $\log_b n$ livelli dell'albero di ricorsione, e si aggiunge un fattore $\log n$ alla soluzione: $T(n) = \Theta(n^{\log_b a} \log n)$.

**Esempio 1.** $T(n) = 2T(n/4) + \sqrt{n}$: $a = 2$, $b = 4$, $\log_4 2 = \tfrac{1}{2}$; $f(n) = n^{1/2} = \Theta(n^{1/2})$ → caso 2. **Risultato:** $\Theta(\sqrt{n} \log n)$.

**Esempio 2.** $T(n) = 4T(n/4) + n$: $\log_4 4 = 1$; $f(n) = n = \Theta(n^1)$ → caso 2. **Risultato:** $\Theta(n \log n)$.

**Esempio 3.** $T(n) = 2T(n/2) + n$ (MergeSort): $\log_2 2 = 1$; $f(n) = n = \Theta(n)$ → caso 2. **Risultato:** $\Theta(n \log n)$.

**Esempio 4.** $T(n) = T(n/8) + 8$: $a = 1$, $b = 8$, $\log_8 1 = 0$; $f(n) = 8 = \Theta(n^0)$ → caso 2. **Risultato:** $\Theta(\log n)$.

**Trappola:** dimenticare il fattore $\log n$: nel caso 2 il risultato è sempre $\Theta(n^{\log_b a} \log n)$, mai $\Theta(n^{\log_b a})$ da solo. È l'errore più frequente su questa casistica.
## Master Theorem — caso 1
> [!question] Traccia tipica
> Data la ricorrenza $T(n) = aT(n/b) + f(n)$, determinare l'ordine asintotico quando $f(n) = O(n^{\log_b a - \varepsilon})$ per qualche $\varepsilon > 0$ (la ricombinazione è polinomialmente più piccola del costo delle foglie).

**Svolgimento.** Nel caso 1 il lavoro alle foglie domina. Occorre trovare un $\varepsilon > 0$ esplicito che certifichi la condizione. Non ci sono fattori logaritmici nella soluzione: $T(n) = \Theta(n^{\log_b a})$.

**Esempio 1.** $T(n) = 4T(n/2) + n\sqrt{n}$: $a = 4$, $b = 2$, $\log_2 4 = 2$; $f(n) = n^{3/2}$, con $3/2 < 2$ e $\varepsilon = 1/2$ → caso 1. **Risultato:** $\Theta(n^2)$.

**Esempio 2.** $T(n) = 4T(n/2) + n^{9/5}$: $\log_2 4 = 2$; $f(n) = n^{9/5}$, con $9/5 < 2$ e $\varepsilon = 1/5$ → caso 1. **Risultato:** $\Theta(n^2)$.

**Esempio 3.** $T(n) = 2T(n/4) + 1$: $a = 2$, $b = 4$, $\log_4 2 = 1/2$; $f(n) = 1 = n^0$, con $0 < 1/2$ e $\varepsilon = 1/2$ → caso 1. **Risultato:** $\Theta(\sqrt{n})$.

**Trappola:** $T(n) = 3T(n/2) + n$: $\log_2 3 \approx 1.585$; $f(n) = n < n^{1.585}$, quindi è caso 1 con **Risultato:** $\Theta(n^{\log_2 3})$, NON $\Theta(n)$. Quando $\log_b a > 1$ è facile sottovalutare il peso delle foglie.
## Master Theorem — caso 3
> [!question] Traccia tipica
> Data la ricorrenza $T(n) = aT(n/b) + f(n)$, determinare l'ordine asintotico quando $f(n) = \Omega(n^{\log_b a + \varepsilon})$ e vale la condizione di regolarità $a\,f(n/b) \leq c\,f(n)$ per qualche $c < 1$.

**Svolgimento.** Nel caso 3 la ricombinazione domina le foglie. Oltre a verificare che $f$ sia polinomialmente più grande di $n^{\log_b a}$, occorre controllare la regolarità: $a\,f(n/b) \leq c\,f(n)$ con $c < 1$. Se entrambe le condizioni sono soddisfatte: $T(n) = \Theta(f(n))$.

**Esempio 1.** $T(n) = T(n/3) + n$: $a = 1$, $b = 3$, $\log_3 1 = 0$; $f(n) = n \gg n^0 = 1$ con $\varepsilon = 1$. Regolarità: $f(n/3) = n/3 \leq \tfrac{1}{3}n$ con $c = 1/3 < 1$ ✓. **Risultato:** $\Theta(n)$.

**Esempio 2.** $T(n) = 2T(n/3) + n$: $\log_3 2 \approx 0.63$; $f(n) = n > n^{0.63}$ con $\varepsilon \approx 0.37$. Regolarità: $2 \cdot n/3 = 2n/3 \leq cn$ con $c = 2/3 < 1$ ✓. **Risultato:** $\Theta(n)$.

**Esempio 3.** $T(n) = 2T(n/4) + n\sqrt{n}$: $\log_4 2 = 1/2$; $f(n) = n^{3/2} \gg n^{1/2}$ con $\varepsilon = 1$. Regolarità: $2(n/4)^{3/2} = 2 \cdot n^{3/2}/8 = n^{3/2}/4 \leq \tfrac{1}{4}f(n)$ con $c = 1/4 < 1$ ✓. **Risultato:** $\Theta(n\sqrt{n})$.

**Trappola:** $T(n) = 7T(n/8) + n$: $\log_8 7 \approx 0.936 < 1$, quindi $f(n) = n > n^{0.936}$ → è caso 3, NON caso 1. La condizione $\log_b a < 1$ non implica automaticamente che si sia nel caso 1.
## Ricorrenza sottrattiva con a ≥ 2
> [!question] Traccia tipica
> Data la ricorrenza $T(n) = aT(n-k) + f(n)$ con $a \geq 2$ e $k \geq 1$, determinare l'ordine asintotico.

**Svolgimento.** Il Master Theorem NON si applica: l'argomento ricorsivo è $n - k$, non $n/b$. Si analizza l'albero di ricorsione: al livello $i$ ci sono $a^i$ nodi, ciascuno con costo $f(n - ik)$. La profondità dell'albero è $\Theta(n/k)$. La somma totale dei costi è dominata dalla progressione geometrica $\sum_{i=0}^{n/k} a^i = \Theta(a^{n/k})$; qualunque $f$ polinomiale non altera l'ordine esponenziale.

**Esempio 1.** $T(n) = 2T(n-2) + 1$: $a = 2$, $k = 2$; $\sum_{i=0}^{n/2} 2^i = \Theta(2^{n/2})$. **Risultato:** $\Theta(2^{n/2})$.

**Esempio 2.** $T(n) = 2T(n-4) + 1$: $a = 2$, $k = 4$. **Risultato:** $\Theta(2^{n/4})$.

**Esempio 3.** $T(n) = 2T(n-2) + n$: $f(n) = n$ non altera l'ordine esponenziale; la somma $\sum_{i=0}^{n/2}(n - 2i)\,2^i$ è ancora $\Theta(2^{n/2})$. **Risultato:** $\Theta(2^{n/2})$.

**Trappola:** l'esponente è $n/k$, non $n$. Raddoppiare $k$ (da $2$ a $4$) dimezza l'esponente ($n/2$ diventa $n/4$), ma la crescita resta esponenziale con la stessa base $a$.
## Ricorrenza sottrattiva con a = 1
> [!question] Traccia tipica
> Data la ricorrenza $T(n) = T(n-k) + f(n)$ con $a = 1$ e $k \geq 1$, determinare l'ordine asintotico srotolando la ricorrenza.

**Svolgimento.** Con $a = 1$ non c'è moltiplicazione del numero di sottoproblemi: srotolando si ottiene $T(n) = f(n) + f(n-k) + f(n-2k) + \dots + T(1)$. Per $k = 1$: $T(n) = \sum_{j=1}^{n} f(j)$. Se $f(j) = \Theta(j^p)$, allora $\sum_{j=1}^n j^p = \Theta(n^{p+1})$, con il risultato più elevato di un grado rispetto a $f$.

**Esempio 1.** $T(n) = T(n-1) + n^2$: $\sum_{j=1}^n j^2 = \Theta(n^3)$. **Risultato:** $\Theta(n^3)$.

**Esempio 2.** $T(n) = T(n-1) + n^3$: $\sum_{j=1}^n j^3 = \Theta(n^4)$. **Risultato:** $\Theta(n^4)$.

**Esempio 3.** $T(n) = T(n-1) + \sqrt{n}$: $\sum_{j=1}^n j^{1/2} = \Theta(n^{3/2})$. **Risultato:** $\Theta(n^{3/2})$.

**Trappola:** non confondere con la sottrattiva $a \geq 2$: con $a = 1$ la crescita è polinomiale ($\Theta(n^{p+1})$), con $a \geq 2$ è esponenziale ($\Theta(a^{n/k})$). Sbagliare la classificazione porta a un ordine completamente diverso.
## Ricorrenza tipo Fibonacci
> [!question] Traccia tipica
> Determinare l'ordine asintotico di $T(n) = T(n-1) + T(n-2) + f(n)$ con $f(n) = O(1)$.

**Svolgimento.** Né il Master Theorem né lo srotolamento lineare si applicano: la ricorrenza ha due chiamate con argomenti distinti. Si usa l'equazione caratteristica. Considerando la ricorrenza omogenea $T(n) = T(n-1) + T(n-2)$ e ponendo $T(n) = x^n$, si ottiene $x^2 = x + 1$, ovvero $x^2 - x - 1 = 0$. Le radici sono:
$$\varphi = \frac{1+\sqrt{5}}{2} \approx 1.618, \qquad \hat\varphi = \frac{1-\sqrt{5}}{2} \approx -0.618.$$
Poiché $|\hat\varphi| < 1$, la soluzione è dominata da $\varphi^n$. Un termine additivo $f(n) = O(1)$ non altera l'ordine esponenziale.

**Esempio.** $T(n) = T(n-1) + T(n-2) + 1$: l'equazione caratteristica è $x^2 - x - 1 = 0$, radice dominante $\varphi$. **Risultato:** $\Theta(\varphi^n)$.

Questo è esattamente il costo dell'algoritmo ricorsivo ingenuo descritto in [[01 - Il Problema di Fibonacci]]: ogni chiamata genera due sottoproblemi, producendo un albero di ricorsione con $\Theta(\varphi^n)$ nodi.

**Trappola:** tentare il Master Theorem o uno srotolamento lineare su questa ricorrenza porta a risultati errati; è obbligatorio usare l'equazione caratteristica (o il conteggio diretto dei nodi dell'albero di ricorsione).
## Cambio di variabile (argomento radice)
> [!question] Traccia tipica
> Determinare l'ordine asintotico di $T(n) = T(\sqrt{n}) + f(n)$, dove l'argomento della ricorrenza è $\sqrt{n}$ anziché $n/b$.

**Svolgimento.** Il Master Theorem non si applica direttamente perché l'argomento è $\sqrt{n}$, non $n/b$. Si esegue il cambio di variabile $m = \log_2 n$ (equivalentemente $n = 2^m$) e si pone $S(m) = T(2^m)$. Osservando che $\sqrt{2^m} = 2^{m/2}$, la ricorrenza si riscrive:
$$S(m) = S(m/2) + f(2^m).$$
Questa è nella forma del Master Theorem con $a = 1$ e $b = 2$. Risolta $S(m)$, si ritraduce sostituendo $m = \log_2 n$.

**Esempio.** $T(n) = T(\sqrt{n}) + 1$:
- Cambio di variabile: $m = \log_2 n$, $S(m) = T(2^m)$.
- Ricorrenza trasformata: $S(m) = S(m/2) + 1$.
- $a = 1$, $b = 2$, $\log_2 1 = 0$; $f(m) = 1 = \Theta(m^0)$ → caso 2 del Master Theorem.
- **Risultato intermedio:** $S(m) = \Theta(\log m)$.
- **Ritraduzione:** $m = \log_2 n$, quindi $T(n) = S(\log_2 n) = \Theta(\log \log n)$.

**Risultato:** $\Theta(\log \log n)$. **Complessità:** $\Theta(\log \log n)$.

**Trappola:** dimenticare di ritradurre $m = \log_2 n$ alla fine e consegnare $\Theta(\log m)$ come risposta: la variabile $m$ non ha significato nel problema originale.
