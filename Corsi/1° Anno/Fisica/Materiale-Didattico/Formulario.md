# Vettori

| $\displaystyle v=\sqrt{ v_{x}^{2}+v_{y}^{2} }$  | Calcolo del modulo di un vettore dalle sue componenti |
| ----------------------------------------------- | ----------------------------------------------------- |
| $v_{x}=v\cos(\theta)$                           | Calcolo della componente x da modulo e angolo (fase)  |
| $v_{y}=v\sin(\theta)$                           | Calcolo della componente y da modulo e angolo (fase)  |
| $\displaystyle\tan(\theta)=\frac{v_{y}}{v_{x}}$ | Calcolo della tangente dell'angolo di un vettore      |
| $\displaystyle v=v_{x}\hat{i}+v_{y}\hat{j}$     | Rappresentazione di un vettore tramite versori        |
# Cinematica

| $\displaystyle v_{x,med}=\frac{\Delta x}{\Delta t}=\frac{x_{f}-x_{i}}{t_{f}-t_{i}}$         | Velocità media in un moto rettilineo                                     |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| $\displaystyle v_{x}(t)=\frac{dx(t)}{dt}$                                                   | Velocità istantanea (derivata della posizione)                           |
| $\displaystyle a_{x,med}=\frac{\Delta v_{x}}{\Delta t}=\frac{v_{x,f}-v_{x,i}}{t_{f}-t_{i}}$ | Accelerazione media in un moto rettilineo                                |
| $\displaystyle a_{x}(t)=\frac{dv_{x}(t)}{dt}=\frac{d^{2}x(t)}{dt^{2}}$                      | Accelerazione istantanea (derivata della velocità)                       |
| $\displaystyle x(t)=x_{0}+v_{x}t$                                                           | Legge oraria del Moto Rettilineo Uniforme (MRU)                          |
| $\displaystyle v_{x}(t)=v_{x,0}+a_{x}t$                                                     | Legge della velocità del Moto Rettilineo Uniformemente Accelerato (MRUA) |
| $\displaystyle v_{x}(t)=x_{0}+v_{x,0}t+\frac{1}{2}a_{x}t^{2}$                               | Legge oraria del Moto Rettilineo Uniformemente Accelerato (MRUA)         |
| $\displaystyle v_{x}^{2}=v_{x,0}^{2}+2a_{x}(x-x_{0})$                                       | Relazione tra velocità e posizione nel MRUA (indipendente dal tempo)     |
| $\displaystyle \Delta x=\int_{t_{i}}^{t_{f}}v_{x}(t)dt$                                     | Spostamento come integrale della velocità (Moto Vario)                   |
| $\displaystyle \Delta v_{x}=\int_{t_{i}}^{t_{f}}a_{x}(t)dt$                                 | Variazione di velocità come integrale dell'accelerazione (Moto Vario)    |
